# CryptoAssessment

Небольшое iOS-приложение для просмотра информации о криптовалютах.
Проект выполнен как тестовое задание.

Приложение показывает список монет, позволяет искать и сортировать их, открывать детальную информацию и смотреть график изменения цены.

## Что реализовано

- mock-авторизация
- список криптовалют
- поиск по названию
- сортировка по имени, цене и изменению за 24 часа
- pull-to-refresh
- экран деталей монеты
- график цены
- обработка состояний загрузки и ошибок
- работа с CoinGecko API

## API key

Данные загружаются через CoinGecko API.

Приложение может работать без ключа, но в таком режиме запросы могут быстрее попасть под rate limit. Для более стабильной работы можно добавить Demo API key.

В Xcode:

1. Открыть scheme
2. Перейти в `Run -> Arguments`
3. Добавить environment variable:

```text
COINGECKO_API_KEY=your_api_key_here
```
